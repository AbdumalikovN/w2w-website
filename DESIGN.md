# DESIGN.md — дизайн-система сайта Win to Win (iOS-стиль)

Источник правды для внешнего вида. Токены — в `src/assets/css/main.css` (`:root`), интерактив и анимации — в `src/assets/js/main.js` (GSAP + ScrollTrigger, файлы в `assets/vendor/`). Основа — брендбук W2W: Onest, Bright Turquoise `#0ABCF3`, Shark `#232325`, Concrete `#F3F3F3`, зелёный `#07E7B7`. Язык интерфейса — iOS: материалы-«стекло», карточки-виджеты, элементы управления iPhone, пружинные анимации.

## Цвет

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#F3F3F3` | фон страницы (Concrete) |
| `--bg-2` | `#FFFFFF` | карточки, секции `.is-paper` |
| `--ink` | `#232325` | текст, основная кнопка (Shark) |
| `--label-2` | `#616166` | вторичный текст (≥ 4.5:1 на фоне) |
| `--brand` | `#0ABCF3` | цвет-поле: результат калькулятора, партнёрство, акценты; текст на нём — чернильный |
| `--green` / `--green-deep` | `#07E7B7` / `#05B58F` | сигнал: «на связи», включённые тумблеры, кольца |
| `--night` | `#0B0B0D` | тёмные сцены: TwinWin, CTA, тёмные первые экраны |

Фоновые «ауры» — размытые радиальные пятна бирюзы и зелёного (`.aurora`, `.hero-page::before/::after`), медленно дрейфуют.

## Типографика

Onest 400–800, самохостинг (`scripts/fetch-fonts.mjs`). Заголовки крупные, плотные, как на страницах Apple.

| Класс | Размер | Начертание |
|---|---|---|
| `.display` | clamp(44px, 6.4vw, 92px), трекинг −0.05em | 800 |
| `.h1` | clamp(40px, 5.8vw, 80px) | 800 |
| `.h2` | clamp(34px, 4.4vw, 62px) | 800 |
| `.lead` | 18–22px, `--label-2` | 500 |
| body | 17px / 1.5 | 400 |

Русский набор делается при сборке (transform `typeset` в `eleventy.config.js`): предлоги и союзы, числа с единицами, группы разрядов («5 000»), диапазоны и короткие слова через дефис не разрываются.

## Материалы и формы

- Стекло: `.glass` (светлое), `.glass-dark` (тёмное) — `backdrop-filter: blur + saturate`, светлая кромка, мягкая тень. Есть фолбэки для `prefers-reduced-transparency` и браузеров без `backdrop-filter`.
- Радиусы: 40px большие панели, 28px карточки, 22px сгруппированные списки, 14px поля, пилюли у кнопок и чипов.
- Иконки приложений `.app-icon` (скруглённый квадрат с градиентом бренда + SVG-глиф из `partials/icons.njk`), тона `.ic-1…8`, `.ic-w`.

## Компоненты

- Шапка — плавающая стеклянная капсула; компактнее после прокрутки, над тёмными секциями переключается на тёмное стекло.
- Кнопки `.btn` (чернильная), `.btn-outline` (стекло), `.btn-brand`, `.btn-on-dark`; нажатие — пружинное уменьшение.
- Калькулятор — как «Настройки» iOS: сгруппированные списки, тумблеры `.switch`, сегмент-контролы `.segmented` с едущим бегунком, степпер, слайдер; результат — бирюзовый виджет с кольцом и полосой «Структура оценки» (как «Экранное время»).
- Сгруппированные списки: `.list`, `.index`, `.faq`, `.ledger`, `.industries`, `.stack`, `.facts` — белые карточки с внутренними разделителями.
- Bento-сетки `.bento/.tile`, виджеты-цифры `.figures`, карточки агентов `.agent-card`, проекты `.pcard/.cover`, люди `.person/.portrait`.
- Модалки — «шторки»: на телефоне выезжают снизу с ручкой, на десктопе — стеклянная карточка.
- Таблицы на телефоне превращаются в карточки списка (подписи столбцов подставляет JS).

## Движение

- Главная: заголовок проявляется по словам из размытия; телефон поднимается, уведомления агентов приходят каждые 3 секунды; виджеты вокруг — параллакс.
- Текст-манифест подсвечивается по мере прокрутки; счётчики докручиваются.
- Лента агентов закреплена и едет вбок при прокрутке (на телефоне — свайп).
- Кольца этапов заполняются, пока этапы проезжают мимо закреплённых колец.
- TwinWin: запрос печатается, скелетон «ищет в источниках», ответ и источники появляются с пружиной.
- Карточки и заголовки всех страниц появляются при прокрутке; наклон карточек за курсором; переходы между страницами (View Transitions).
- `prefers-reduced-motion`: все анимации выключаются, контент показан сразу. Без JS сайт полностью читаем.

## Инварианты

Onest — единственный шрифт; текст на бирюзе — чернильный; зелёный — только сигнал; контраст текста ≥ 4.5:1; каждое стекло поверх чего-то, что можно размыть; анимации не прячут контент без JS.
