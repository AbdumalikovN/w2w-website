# Win to Win — сайт w2w.uz (Website 2.0)

Репозиторий нового сайта компании **Win to Win (W2W)**. Сейчас здесь опубликован кликабельный ч/б прототип **v2** (34 страницы) — основа, по которой дальше делается полноценный сайт.

## Что внутри

- `index.html` — прототип v2, один автономный файл: разметка + стили + JS. Роутинг по hash (`#/services/agents`, `#/team/ceo` и т.д.), все страницы — функции в объекте `views`. Поиск по сайту: `Ctrl+K` / `Cmd+K`. Открывается локально двойным кликом, интернет не нужен (кроме шрифта Onest с Google Fonts).
- `netlify.toml` — настройки публикации (статический сайт, корень репозитория).
- `.nojekyll` — отключает Jekyll-обработку на GitHub Pages.

## Что нового в v2 (09.09.2026)

1. Главная развёрнута на **AI-агентов** — аутсорсинг агентских решений как основной фокус.
2. Раздел **«Команда»** + персональные лендинги четырёх руководителей (директор, коммерческий, технический, операционный).
3. **Калькулятор стоимости AI-агента** — на главной и отдельной страницей. Выдаёт диапазон, минимум $5 000.
4. Новые страницы: `#/services/agents`, `#/twinwin`, `#/calculator`, `#/team`, `#/team/{ceo,cco,cto,coo}`.

## Разработчику

- Калькулятор в прототипе считает на клиенте (демо-модель) — это **заглушка**. Контракт `POST /api/estimate`, требования к бэкенду и правила ценообразования описаны в комментарии к блоку «v2: КАЛЬКУЛЯТОР» в исходнике.
- Данные, помеченные пунктиром («НА УТОЧНЕНИИ»), заполняются владельцем без изменения вёрстки.
- Полный бриф проекта (решения, тексты, структура) хранится отдельно в рабочих материалах проекта, не в этом репозитории.
